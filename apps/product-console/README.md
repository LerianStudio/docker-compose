# Product Console

## Quick Start

1. **Clone the Repository:**
```bash
git clone https://github.com/LerianStudio/plugins-docker-compose.git
```

2. **Go to the product directory:**
```bash
cd plugins/product-console
```

3. **Run the Docker Compose File**
```bash
docker compose up
```

4. **Access the Console:**
Visit `http://localhost:8081` to interact with the Console.

5. [Visit our Documentation](https://docs.lerian.studio/en/platform/lerian-console/about-lerian-console#console-overview)
